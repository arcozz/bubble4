# Middle Click Sparks + Tab Open Animations for Zen

Deux effets, indépendants l'un de l'autre :

1. **Étincelles au clic milieu** sur un lien (ou Ctrl+clic) : effet d'origine, inchangé.
2. **Animation à l'ouverture d'un onglet** : Comète (défaut), Laser, Bulles ou Aléatoire.
   Les effets sont dessinés par-dessus la fenêtre et peuvent dépasser de la sidebar.

La **comète part du clic** : si l'onglet s'ouvre juste après un clic milieu / Ctrl+clic sur un lien,
elle vole du curseur jusqu'au nouvel onglet. Sinon (Ctrl+T, raccourci...), elle part d'un point par défaut.
Laser et Bulles s'inversent automatiquement si la sidebar est à droite.

## Réglages
- Étincelles : nombre, longueur, épaisseur, distance, durée.
- Onglet : case pour activer/désactiver, style d'animation, vitesse en % (160 = référence).
- Les onglets restaurés au démarrage ne sont pas animés.
- Si rien ne s'affiche : active **Debug**, ouvre la Console (Ctrl+Shift+J).
